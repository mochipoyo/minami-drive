# 動作確認（自動テスト）

修正のたびに、起動・入力・保存データ・時間の進み方・採点・26教習と特殊モードの基本動作を自動で確かめるためのテストです。
Playwright で Chromium を動かし、このリポジトリを手元の Web サーバーで配信して確認します。
公開用の `index.html` には含まれません（`build.py` が連結するのは `src/js/` だけです）。

## 必要なもの

- Node.js 18 以上
- 初回だけインターネット接続（`npm install` と Playwright 用ブラウザのダウンロード）

## 使い方

```
cd tests
npm install
npx playwright install chromium   # 初回だけ
npm test                          # すべて実行
npm run screens                   # 比較用のスクリーンショット（results/screens/ に保存）
```

一部だけ実行したり、条件を変えたりするときは、環境変数を使います（macOS・Linux の例）。

```
SUITES=boot,input npm test        # 起動と入力だけ
GL=gpu npm test                   # 実際のGPUで描画する（速い）
HEADED=1 SUITES=lessons npm test  # ブラウザの画面を表示しながら
SITE_ROOT=../../別のフォルダ npm test  # 変更前の版など、別のフォルダを確かめる
```

既定では GPU のない環境でも動くよう、ソフトウェア描画（SwiftShader）を使います。そのため全体で20〜40分ほどかかります。
結果は画面に表示され、`results/latest.json` にも保存されます（`results/` は Git に含めません）。

## 確かめていること

| テスト | 内容 |
|---|---|
| `suite-boot.mjs` | PC（1920×1080・1366×768）とスマホ（390×844・844×390）で起動できる。フォントの CSS が応答しない・読み込めないときも起動する。three.js の CDN が使えないときは予備の CDN で起動し、どちらも使えないとき・WebGL が使えないときは理由と再読み込みボタンを出す。3D表示が中断されたら一時停止して知らせ、復帰したら表示が戻る。端末を回転させると描画の大きさと縦横比が合う 。SNS 共有用の OGP / Twitter Card のタグと画像（assets/ogp.jpg、1200×630）がそろっている|
| `suite-input.mjs` | キーやタッチを押したままフォーカスを失ったり、ほかのアプリに切り替えたりしても、アクセル・ブレーキ・ハンドル・クラクションが押しっぱなしにならない。pointercancel で離した状態になる。矢印キーでページがスクロールしない |
| `suite-timing.mjs` | 画面が隠れたら一時停止し、その間は進まず減点もされない。処理が1.5秒止まっても、ゲームの時間が一気に進まない |
| `suite-storage.mjs` | 保存データがない・壊れている・型が違う・保存できないときでも起動し、表示が崩れない。いまの形式の記録は消さない |
| `suite-scoring.mjs` | 100点から始まる、速度超過の減点、結果画面の違反と条文、重大な違反で不合格、0点の下限、自由走行は採点しない、事故の画面、ベスト記録の保存と再読み込み後の表示 |
| `suite-lessons.mjs` | 既存の26教習がそろっていて順番が変わらないこと（そのあとに特殊モード1つ、東京・新宿5つ、自由走行1つ）。26教習と特殊モードそれぞれを、メニューから開始 → やり直し → メニューにもどる。代表的な教習（既定：s1・s4・e1・e3）はお手本の自動運転で最後まで走り、結果画面と「もう一度」を確かめる |
| `suite-assets.mjs` | 車の3Dモデル（assets/cars）：11車種が読み込めて車が差し替わる（自転車・バイクはそのまま）。ブレーキ・ウインカーの表示が引き継がれる。近くは近く用・遠くは遠く用の形。assets/ が読み込めなくても今までの形で最後まで走れる。PC（画質「高」）では路面の凹凸・塗装のつや・雲、雨で路面が濡れる。スマホ（低）では今までの材質 |
| `suite-shinjuku.mjs` | 東京・新宿駅周辺：地図データが裏で読み込まれ、原簿に「東京」が出る。道路網（300本以上・交差点150以上、すべて多角形の交差点、信号あり）ができて車と歩行者が出る。右左折の線の上は走れる所になっている。右折レーンが分離帯の広い幹線の信号交差点の手前にあり、近い信号どうしは同じ周期にそろっている。5つの教習（甲州街道・明治通り・靖国通り・歌舞伎町の裏道・西新宿の右折レーン）を自動運転で事故なく走りきれる（右折レーンの教習は右折レーンから右折する）。地図データを読み込めないときは案内を出して原簿に戻れ、みなみ町はそのまま走れる。既存の地図は今までの交差点の形のまま |

## しくみの補足

- three.js は CDN の代わりに `node_modules` の同じ版（r128）を返すので、テスト中に CDN へはつなぎません。
- Google Fonts の CSS は空の内容を返します（フォントなしで表示されます）。フォントの CSS が応答しないとき・読み込めないときは、`suite-boot.mjs` で別に確かめています。
- 交通や歩行者の乱数（`Math.random`）は固定しています。教習の乱数は、テスト用の入口（`startStage`）から始める確認では `window.__seed` で固定しています（メニューのボタンから始める26教習の確認では固定していません）。
- メニューを表示している間も町の車や歩行者は動くので、ページを開いてから教習を始めるまでの時間で結果が少し変わることがあります。同じページで教習を続けると信号の周期などが前の教習に左右されるため、結果を比べる場面ではページを読み込み直しています。
- ゲームの開発・テスト用の入口 `window.__sim` を使います。
